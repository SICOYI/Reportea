## Title
Graph Neural Network enhanced Finite Element modelling

## Authors
- Rutwik Gulakala
- Bernd Markert
- Marcus Stoffel

*Institute of General Mechanics (IAM), RWTH Aachen University, Aachen, Germany*

## Abstract
A Graph Network-enhanced Finite Element (GNN-FE) approach is proposed to accelerate FE simulations. The method uses discretized geometry from an FE pre-processor as a graph input and employs a GNN with learned message-passing to solve boundary value problems, predicting von-Mises stress distributions at each node — without relying on image-based inputs/outputs as done in prior literature.

## Keywords
- Graph Neural Networks (GNN)
- Finite Element Method (FEM)
- Message-passing
- Von-Mises stress
- Surrogate modelling
- Elastoplasticity

## Research Problem
- FE simulations are computationally expensive, especially for complex boundary value problems (e.g., crash simulations).
- Existing ML surrogates (CNNs) are limited to structured rectangular domains and use images as I/O, making them unsuitable for unstructured FE meshes.
- A gap exists for a method that directly interfaces with FE pre/post-processors using native mesh data.

## Methodology
- **Domain:** Rectangular aluminium plates with holes at various locations/sizes; elastoplastic material modelled using the isotropic Johnson-Cook constitutive model.
- **Data generation:** ABAQUS FE solver; Python scripting for automation; ODB2VTK for format conversion; 540 total samples (500 training, 40 test).
- **Graph construction:** Undirected, homogeneous, static graph; FE nodes → graph nodes; FE elements → graph edges.
- **Network architecture:** Encoder-Decoder with:
  - Transformer convolution layers as aggregation function
  - MLP as message-passing function
  - Material data concatenated to latent vector via FFNN
- **Training:** Adam optimizer, MSE loss, learning rate 3E-3 with exponential decay from epoch 200; 1000 epochs total.
- **Hyperparameter tuning:** Hyperband search algorithm; selected: 3 transformer conv. layers, 16 latent units, 5 MLP decoder layers.

## Key Findings
- Test MSE of **5.89E-2** across the full test batch.
- Stress prediction error ranges from ~1.7E9–2.9E10 GPa depending on geometry/loading case.
- GNN results show excellent visual and quantitative correlation with ABAQUS FE results.
- **12.7% computational gain** achieved over standard FE simulation (inclusive of training cost).
- Good extrapolation performance on cases outside the training distribution, with slightly higher error at stress concentration regions (e.g., hole boundaries).

## Contributions
- First approach to directly use FE pre-processor mesh data (nodal coordinates, boundary conditions, edge connectivity) as GNN input — bypassing image-based I/O.
- Output is embedded back into VTK format, enabling direct visualization in FE post-processors.
- Incorporation of mechanics knowledge (material parameters, BCs) into the network improves generalization across varied loading and boundary conditions.

## Limitations
- Moderate computational speedup (12.7%); benefit may be limited for small datasets.
- Higher prediction error observed near stress concentrations (hole boundaries), where gradients are steep.
- Only 2D rectangular plates with holes considered; generalization to complex 3D geometries is not demonstrated.
- Single material (aluminium with Johnson-Cook model); multi-material or highly nonlinear cases are not evaluated.
- Static, undirected graph only; dynamic or directed graph formulations are not explored.

## Conclusion
The proposed GNN-FE framework demonstrates that graph neural networks can effectively replicate FE stress predictions on unstructured meshes using native mesh data, offering a computationally faster and physically informed alternative to conventional FE solvers. While current gains are modest, the approach establishes a viable path for mesh-native, physics-aware surrogate modelling that integrates directly with standard FE workflows.
