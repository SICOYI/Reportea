**Graph Neural Network Enhanced Finite Element Modelling**

## Abstract
This study presents a Graph Network-enhanced Finite Element (FE) approach to accelerate FE simulations. A GNN is applied directly to the discretized FE geometry (nodes and elements as graph entities) to solve boundary value problems, incorporating mechanics knowledge to improve generalization across loading and boundary conditions. Unlike prior work using images as I/O, this model ingests raw FE pre-processor data and outputs von-Mises stress at each node in a format readable by FE post-processors.

## Research Problem
- FE simulations are computationally expensive, particularly for complex problems like crash simulations.
- Existing ML surrogates (CNNs) are limited to structured rectangular domains and cannot handle unstructured meshes.
- Prior GNN-based FE surrogates rely on image inputs/outputs, losing direct compatibility with FE pre/post-processors.

---

## Methodology
- **Domain**: Rectangular aluminium plates with holes at varying locations and sizes; elastoplastic material modelled via isotropic Johnson-Cook model.
- **Data generation**: 540 samples generated using ABAQUS FE solver; ODB files converted to VTK format via ODB2VTK interface.
  - Plate dimensions: 0.2–0.4 m; displacement loading: 0.01–0.1 m; 6 geometric cases × 9 plates × 10 loads.
- **Graph construction**: Undirected, homogeneous, static graph; FE nodes → graph nodes; FE elements → graph edges.
- **Architecture**: Encoder-Decoder GNN
  - Encoder: Transformer convolution layers (aggregation) + MLP (message passing)
  - Latent vector concatenated with material data
  - Decoder: MLP reconstructing output node feature vector (von-Mises stress)
- **Training**: 500/540 samples for training; 1000 epochs; Adam optimizer; MSE loss; learning rate 3E-3 with exponential decay from epoch 200.
- **Hyperparameter tuning**: Hyperband search algorithm
  - 3 transformer convolution layers, 16 latent units, 5 MLP decoder layers.

---

## Key Findings
- Test set MSE error: **5.89E-2**; stress error range: ~1.7E9–2.9E10 GPa across geometry/loading cases.
- GNN predictions show **excellent correlation** with FE simulation results, preserving elemental integrity and overall stress distribution structure.
- A **12.7% computational gain** was observed compared to standard FE simulation (including training cost).
- The model demonstrates reasonable extrapolation capability beyond the trained loading/geometry limits.

---

## Contributions
- First GNN-FEM framework to operate directly on **FE pre-processor data** (nodal coordinates, boundary conditions, edge connectivity) rather than image representations.
- Output is directly compatible with **FE post-processors** (VTK format), enabling seamless integration into existing FE workflows.
- Incorporation of **domain mechanics knowledge** (material parameters as latent inputs) improves generalization across varied loading and boundary conditions.
- Demonstrated applicability to **unstructured, complex geometries** — a limitation of CNN-based surrogates.

---

## Limitations
- Modest computational gain (12.7%), limiting immediate industrial appeal for highly complex simulations.
- Dataset is relatively small (540 samples) and restricted to a single geometry class (plates with holes).
- Only von-Mises stress is predicted; displacement fields and other quantities are not addressed.
- Extrapolation performance beyond trained limits is discussed but not fully quantified.
- Evaluated only on a single material model (Johnson-Cook elastoplastic aluminium).

---

## Conclusion
This work establishes a GNN-based surrogate that directly interfaces with FE pre- and post-processors, overcoming the domain-shape limitations of CNN surrogates. By embedding material and boundary condition data into the graph representation and using a Transformer convolution + MLP encoder-decoder architecture, the model accurately replicates von-Mises stress distributions from FE simulations with a measurable speedup. The approach provides a promising foundation for physics-augmented GNN surrogates applicable to complex, unstructured engineering domains.
